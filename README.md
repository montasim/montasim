## Open-source packages

```bash
npm install http-status-lite
npm install content-types-lite
npm install client-parser
npm install address-bd
```

- [`http-status-lite`](https://www.npmjs.com/package/http-status-lite) — HTTP status constants, metadata, parsing, and range predicates
- [`content-types-lite`](https://www.npmjs.com/package/content-types-lite) — HTTP media-type constants and parsing utilities
- [`client-parser`](https://www.npmjs.com/package/client-parser) — User-Agent and Client Hints classification
- [`address-bd`](https://www.npmjs.com/package/address-bd) — bilingual Bangladesh administrative data and search

Each package repository documents its compatibility, API, validation, release process, and license. Their linked demo applications provide runnable examples before installation.

## How I maintain projects

My active repositories aim to make trust visible through:

- a product-first README and the shortest reproducible setup path;
- CI, tests, release or deployment evidence where the project supports them;
- explicit privacy, data provenance, security, and limitation notes where they matter;
- issue, contribution, funding, and license paths that match the files actually present;
- small APIs and documentation generated or checked against the implementation.
